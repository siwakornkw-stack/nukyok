ตัวเชื่อม nukyok -> Express (ติดตั้งที่เครื่อง Office)
=====================================================

ทำอะไร
  เครื่องนี้ถามเว็บทุก 1 นาทีว่ามีรายการรอลง Express หรือไม่ ถ้ามีก็ลงให้เอง
  - น้ำมัน: Office กดอนุมัติ (เติมที่ปั๊ม) -> PK + H3 -> R3 ตามวันที่ในบิล
  - งานซ่อม: จัดซื้อบันทึกค่าซ่อม -> PO + RR (ซื้อเงินเชื่อกับอู่ บัญชีตามรหัสค่าซ่อม) -> แจ้ง LINE ผู้บริหารและฝ่ายบัญชี
  - ราคาซื้อย้อนหลัง 2 ปีและข้อมูลผู้ขาย (อ่านอย่างเดียว ไม่เขียน Express) -> หน้าเทียบราคาของจัดซื้อ
    ไม่ส่งเงินเดือน ค่าแรงที่จ่ายบุคคล เงินยืม เงินสดย่อย และผู้ขายที่เป็นพนักงาน
    บุคคลธรรมดาส่งแค่ชื่อ (ไม่ส่งเลขประจำตัว ที่อยู่ เบอร์โทร หมายเหตุ)
  ผลลัพธ์ดูได้ในเว็บ หน้า "Express" (/office/express)
  ถ้าเครื่องปิด รายการจะรออยู่ในคิว เปิดเครื่องแล้วลงต่อเอง ไม่หาย

ก่อนติดตั้ง (ครั้งเดียว)
  1. ใช้เครื่องที่มีข้อมูล Express (หรือเปิดโฟลเดอร์ Express ผ่านวงแลนได้) และเปิดเครื่องไว้ช่วงทำงาน
  2. ติดตั้ง Node.js รุ่น LTS (22 ขึ้นไป) จาก https://nodejs.org (กด Next ตามค่าเริ่มต้น)
  3. ติดตั้ง Microsoft Visual FoxPro OLE DB Provider 9.0 SP2: ไฟล์ VFPOLEDBSetup.msi จาก
     https://github.com/VFPX/VFPInstallers (คลิกขวาที่ไฟล์ > Properties > Digital Signatures ต้องเป็น Microsoft Corporation)
     ถ้าไม่มี ตัวเชื่อมจะอ่านข้อมูลจาก Express ได้อย่างเดียว ลงเอกสารไม่ได้

ติดตั้ง
  1. คัดลอก nukyok-office-agent.zip มาที่เครื่อง คลิกขวา > Extract All
  2. เข้าโฟลเดอร์ที่แตกแล้ว ดับเบิลคลิก install.cmd แล้วกด Yes
     (ถ้าขึ้น "Windows protected your PC" กด More info > Run anyway)
  3. ตอบคำถาม (กด Enter = ใช้ค่าในวงเล็บ)
     - โฟลเดอร์บริษัท: บริษัทที่ลงบัญชีจริงเท่านั้น (zip นี้ต่อกับเว็บจริง ดูหัวข้อถัดไป)
     - น้ำมัน: y
     - งานซ่อม: y เล่ม PO: PO
     - Express อยู่บนเครื่องอื่นในวงแลน: พิมพ์แบบ \\ชื่อเครื่อง\โฟลเดอร์ (ไดรฟ์ที่แมปไว้เช่น Z: ใช้ไม่ได้)
  4. ตัวติดตั้งจะทดสอบ 2 รอบ: รอบแรกส่งข้อมูลหลักไปเว็บอย่างเดียว (ไม่เขียน Express) รอบสองรันจาก Task Scheduler
     ถ้าขึ้น "ติดตั้งเสร็จ" = ใช้งานได้ ตัวจริงอยู่ที่ C:\nukyok-agent
     แล้วลบโฟลเดอร์ที่แตก zip และไฟล์ zip ทิ้ง (มีรหัสลับของเว็บ)
  5. เปิดเว็บหน้า Express ดูว่า "ส่งข้อมูลล่าสุด" เป็นเวลาตอนนี้ น้ำมันขึ้น "เปิดใช้"
     และจำนวนปั๊ม / รหัสรถไม่เป็น 0 (ถ้าเป็น 0 = บริษัทนี้ไม่มีใบสั่งซื้อน้ำมันตั้งแต่ปี 2568 แจ้งผู้ดูแลระบบ)

zip นี้ต่อกับเว็บจริง
  - ห้ามติดตั้ง zip นี้กับบริษัททดสอบ (TESTR3) หรือบริษัทอื่น: บิลจริงที่รออยู่ในคิวจะไปลงบริษัทนั้นแทน
    (ตัวติดตั้งไม่รับโฟลเดอร์ TESTR3)
  - เว็บรับเฉพาะบริษัทที่ตั้งไว้บนเซิร์ฟเวอร์ (EXPRESS_COMPANY เช่น DHEWA66) ถ้าเลือกโฟลเดอร์บริษัทอื่น
    การทดสอบเชื่อมต่อจะไม่ผ่าน และขึ้นข้อความบอกชื่อทั้งสองบริษัท: รัน install.cmd ใหม่แล้วเลือกบริษัทให้ถูก
  - ทดสอบการลงเอกสารกับ TESTR3: ผู้ดูแลระบบทำบนเครื่องพัฒนากับเว็บทดสอบเท่านั้น ไม่ใช้ zip นี้

สิ่งที่ต้องตั้งในเว็บ ไม่อย่างนั้นรายการจะไม่เข้าคิว Express (เว็บจะบอกเหตุผลตอนกด)
  - หน้าข้อมูลรถ: รหัสน้ำมันใน Express ของแต่ละคัน (แผนกใช้ตามรหัสน้ำมัน ถ้าต้องการแผนกอื่นให้พิมพ์ในช่องแผนก Express)
  - คนเติม: เลือกปั๊ม (ผู้จำหน่ายใน Express) ใส่เลขที่และวันที่ในใบกำกับภาษี (Express ลงวันที่ตามใบกำกับ)
    ปั๊มที่ไม่มีเลขผู้เสียภาษีใน Express: เว็บส่งแค่ PK ให้คีย์ H3 เอง
  - จัดซื้อ: เลือกร้าน / อู่ และรหัสค่าซ่อมใน Express ใส่เลขที่และวันที่ในใบกำกับภาษี และเลือก VAT ตามใบกำกับ
    รหัสค่าซ่อมในเว็บมีเฉพาะบัญชีค่าซ่อมแซม / อะไหล่ / บำรุงรักษา (5360-xx) รหัสอื่นคีย์ใน Express เอง
    ร้านที่ไม่มีเลขผู้เสียภาษีใน Express เลือก VAT ไม่ได้ (ใส่เลขใน Express ก่อน หรือคีย์เอง)
    รายชื่อร้าน / อู่เรียงตามที่ใช้ล่าสุด
  รายการที่ไม่ได้เข้าคิวขึ้นในหน้า Express: น้ำมันกด "ส่งเข้า Express" ที่นั่น งานซ่อมส่งจากหน้างานซ่อมของจัดซื้อ
  ถ้าคีย์ใน Express เองแล้ว กด "คีย์เองแล้ว"
  งานซ่อมที่ลงไม่สำเร็จ: จัดซื้อแก้ข้อมูลบิล (ร้าน / รหัส / เลขที่ / วันที่ / VAT) แล้วกด "ส่งเข้า Express ใหม่" ที่หน้างานซ่อมได้

ใช้งานประจำวัน
  - บิลที่เว็บส่งเข้า Express แล้ว (น้ำมัน PK / H3, งานซ่อม PO / RR) อย่าคีย์ใน Express ซ้ำ
  - ลงไม่สำเร็จ: ขึ้นที่หน้า Express ในเว็บ และแจ้ง LINE Office ตรวจใน Express แล้วกด "ลองใหม่" หรือ "คีย์เองแล้ว"
    บิลผิดหรือบิลทดสอบ: Office กด "ยกเลิก" (ใส่เหตุผล) แล้วยกเลิกเอกสารที่ลงไปแล้วใน Express เอง
    ถ้ายังไม่ยกเลิกเอกสารใน Express บิลเดียวกันที่ส่งใหม่จะขึ้น "ยังเป็นของรายการที่ยกเลิกแล้ว": ยกเลิกเอกสารใน Express ก่อน
    แล้วกด "ลองใหม่" และถ้าเครื่องนี้เปิด R3 ให้รายการที่เพิ่งยกเลิก เว็บแจ้ง LINE ให้ยกเลิกบรรทัดนั้นใน R3 ด้วย
  - น้ำมันขึ้น "อาจซ้ำ: ใบกำกับ ..." = ใบกำกับนี้มี H3 / PK อื่นของปั๊มนี้ใน Express แล้ว (เช่น ใบเดียวเติมหลายคัน)
    ตรวจใน Express ถ้าเอกสารนั้นเป็นของรถคันอื่น / บิลอื่น และยังไม่มีบิลนี้ Office กด "ยืนยันว่าไม่ซ้ำ"
    (เครื่องนี้เปิด PK / H3 ของบิลนี้แยกให้ในรอบถัดไป) หรือคีย์เองแล้วกด "คีย์เองแล้ว"
  - ปั๊มออกใบกำกับแทนใบเดิมของคำขอที่อนุมัติแล้ว: ยกเลิกเอกสารใน Express และรายการ Express ของคำขอเดิมในหน้า Express
    (ถ้ามี ยกเว้นที่ "คีย์เองแล้ว": ยกเลิกไปพร้อมคำขอ) แล้วกด "ยกเลิก" ที่หน้าเติมน้ำมันของคำขอเดิม จากนั้นจึงอนุมัติคำขอใหม่
  - เดือนภาษีที่ปิดแล้ว (เดือนที่แล้วเมื่อเลยวันที่ 15 และเดือนก่อนหน้า หรือถึงเดือนที่ตั้ง "ยื่น ภ.พ.30 แล้วถึงเดือน" ในหน้า Express):
    น้ำมันลงแค่ PK ให้คีย์ H3 เองโดยลงภาษีซื้อในเดือนที่ยังเปิด งานซ่อมที่มี VAT คีย์ PO / RR เอง
    Office ตั้ง "ยื่น ภ.พ.30 แล้วถึงเดือน" ทุกครั้งที่ยื่นแล้ว
  - เครื่องนี้เงียบเกิน 1 ชั่วโมงขณะมีงานรอ หรือบิลรอเกิน 1 ชั่วโมงทั้งที่เครื่องยังติดต่อ: ระบบแจ้ง LINE Office
  - ก่อนลงเอกสารทุกครั้ง ตารางที่แก้จะถูกสำรองไว้ที่ C:\nukyok-agent\var\express-backups
  - บันทึกการทำงาน: C:\nukyok-agent\var\agent.log
  - โฟลเดอร์ C:\nukyok-agent เปิดได้เฉพาะ SYSTEM และ Administrator (มีรหัสลับ และ Task รันเป็น SYSTEM)
    ถ้า Explorer ถามสิทธิ์ อย่ากด Continue (จะเปิดให้ผู้ใช้นั้นถาวรจนกว่าจะรัน install.cmd ใหม่)
    ให้ใช้ Command Prompt แบบ Administrator แทน (Start > พิมพ์ cmd > คลิกขวา Command Prompt > Run as administrator)
    - ดู log:
        copy C:\nukyok-agent\var\agent.log %USERPROFILE%\Desktop\
    - เขียนลง Express ค้าง: ดูหัวข้อถัดไป
    - ตารางที่สำรองไว้ (มีข้อมูลบุคคลจาก Express อย่าคัดลอกไปเก็บที่อื่น):  dir C:\nukyok-agent\var\express-backups
      คืนทั้งตารางทับข้อมูลใน Express: ผู้ดูแลระบบทำเท่านั้น ปิด Express ทุกเครื่องก่อน และรายการที่ลงหลังเวลาสำรองจะหายไป
        copy /y "C:\nukyok-agent\var\express-backups\<โฟลเดอร์>\<ตาราง>.*" "<โฟลเดอร์บริษัทใน Express>\"

เขียนลง Express ค้างไว้ไม่สมบูรณ์ (เช่น ไฟดับหรือโปรแกรมถูกหยุดระหว่างลงบิล)
  เว็บและ LINE บอกว่า "เขียนลง Express ค้างไว้ไม่สมบูรณ์" พร้อมชื่อไฟล์ ...\var\<ชนิด>-ledger\<รหัส>.json
  บิลอื่นชนิดเดียวกัน (น้ำมัน / งานซ่อม / R3) จะรออยู่ในคิว ยังไม่ลง จนกว่าจะทำครบ 4 ข้อนี้ (ผู้ดูแลระบบทำ
  ใน Command Prompt แบบ Administrator)
  หลักการ: ย้อนบิลที่ค้างออกจาก Express ทั้งบิลตามไฟล์นี้ แล้วให้เครื่องนี้ลงบิลนั้นใหม่ตั้งแต่ต้น
  1. เปิดไฟล์:  notepad "<ไฟล์ที่เว็บบอก>"
     added   = แถวที่บิลนี้เพิ่ม: ชื่อย่อตารางกับเลขระเบียน (record number)
     changed = ช่องที่บิลนี้แก้ในแถวที่มีอยู่แล้ว: ชื่อย่อตาราง (alias) เลขระเบียน (recno) ชื่อช่อง (field)
               และ old = ค่าก่อนบิลนี้แก้ (อักษรหน้า | คือชนิด N ตัวเลข / C ข้อความ / D วันที่ ปปปปดดวว ค.ศ. ค่าอยู่หลัง |)
     ชื่อย่อตาราง: fwpo = POPR, fwpi = POPRIT, fwrn = ISRUN, fwsm = STMAS, fwst / r3st = STCRD, fwap / r3ap = APTRN,
       fwgj / r3gj = GLJNL, fwgi / r3gi = GLJNLIT, fwvt = ISVAT, fwpc = APRCPCQ, fwam / r3am = APMAS, fwab / r3ab = APBAL
     ถ้ามีไฟล์ชื่อเดียวกันต่อท้าย .tmp อยู่ข้างกัน ให้เปิดดูด้วย: แถวใน added ของ .tmp ที่ไม่มีใน .json อยู่ใน Express แล้ว
     ต้องลบด้วย ส่วนช่องใน changed ที่มีแค่ใน .tmp ยังไม่ถูกแก้ใน Express ไม่ต้องทำอะไร
     ถ้าเว็บบอก "ไฟล์บันทึกอ่านไม่ได้": ใช้ added / changed จาก .tmp ข้างกันแทน ถ้าไม่มีหรืออ่านไม่ได้ ให้เทียบตารางใน Express
     กับชุดสำรองก่อนบิลนี้ใน C:\nukyok-agent\var\express-backups (โฟลเดอร์ <ชนิด>-<เวลา> ล่าสุดก่อนบิลนี้ เวลาในชื่อ = เวลาไทยลบ 7 ชม.
     บิลอื่นที่ลงในรอบเดียวกันมีไฟล์บันทึกของตัวเอง) เพื่อหาแถวที่บิลนี้เพิ่มและช่องที่แก้ แล้วปรึกษาฝ่ายบัญชีก่อนแก้
  2. ย้อนบิลนี้ออกจาก Express ทั้งบิล:
     - ทุกแถวใน added: ไปที่แถวตามเลขระเบียน ตรวจว่าเลขเอกสารในแถว (ponum / docnum / voucher / rcpnum) เป็นของบิลนี้
       (แถวสุดท้ายอาจว่าง: เพิ่มแล้วแต่ยังไม่ได้ใส่ค่า) แล้วทำเครื่องหมายลบ (delete) ห้าม PACK ตาราง:
       เลขระเบียนจะเลื่อนไม่ตรงกับไฟล์ และเลขเอกสารที่ข้ามไปอาจถูกใช้ซ้ำ
     - ทุกช่องใน changed แก้กลับเป็นค่า old (old เป็น D| เฉยๆ = วันที่ว่าง)
       ทำจากรายการล่างสุดของ changed ขึ้นไป ช่องเดียวกันที่มีหลายรายการ ค่าที่ถูกคือ old ของรายการแรก
       (น้ำมันแก้ totreo ของรถ 2 ครั้ง: ตอนเปิด PK และตอนลง H3)
     - ก่อนแก้แต่ละช่อง ดูค่าใน Express ตอนนี้ (ยอดบิล วันที่บิล และลิตร ดูจากบิลนั้นในหน้า Express ของเว็บ):
         เป็น old อยู่แล้ว: ไม่ต้องแก้ (ช่องสุดท้ายใน changed อาจยังไม่ถูกแก้ตอนโปรแกรมหยุด)
         เป็นค่าที่บิลนี้ใส่: แก้กลับเป็น old
           เลขรันใน ISRUN = เลข PK / PO ในไฟล์ + 1 (เช่น PK0000005 -> 0000006)
           totreo ใน STMAS (ยอดค้างรับของรถ) = old บวกหรือลบจำนวนลิตรของบิล
           balance ใน APMAS และช่องยอดใน APBAL (ยอดเจ้าหนี้) = old + ยอดบิล
           lasrcv = วันที่บิล (เมื่อวันที่บิลใหม่กว่า old)
         เป็นค่าอื่น: มีคนแก้หลังบิลนี้ค้าง (เช่น มีคนออกเลข PO / PK ใหม่ไปแล้ว หรือคีย์บิลอื่นของผู้ขายหรือรถคันเดียวกัน)
           อย่าใส่ค่า old ทับ ให้ปรึกษาฝ่ายบัญชีก่อน
     ทำแบบนี้ถูกเสมอ ไม่ว่าค่าที่แก้จะลงถึง Express แล้วหรือยัง
     อย่าย้อนแค่บางส่วน (เช่น เก็บ PK / PO ไว้แล้วลบแค่บรรทัดสต็อก): ยอดค้างรับของรถหรือเลขรันจะผิด
  3. ย้ายไฟล์ (และ .tmp ถ้ามี) ออกจากโฟลเดอร์นั้น เก็บไว้เป็นหลักฐาน:
       move "<ไฟล์ที่เว็บบอก>" C:\nukyok-agent\var\
  4. ในหน้า Express กด "ลองใหม่" ที่บิลนั้น: เครื่องนี้ลงใหม่ทั้งบิลด้วยเลขเอกสารใหม่ (เลขที่ค้างถูกข้าม ไม่ใช้ซ้ำ)
     บิลที่รออยู่จะลงต่อเองในนาทีถัดไป (ถ้าจะคีย์บิลนั้นเองหลังย้อนแล้ว กด "คีย์เองแล้ว" / "ทำ R3 เองแล้ว" แทน)
     แล้วตรวจใน Express ว่าบิลนี้มีครั้งเดียว เลขรันของเล่ม (PK / PO) ต่อจากเลขที่เพิ่งลง ยอดค้างรับของรถ (น้ำมัน)
     กลับเท่าก่อนบิลนี้เมื่อลง H3 แล้ว (ลงแค่ PK: เพิ่มเท่าจำนวนลิตร) และยอดเจ้าหนี้ของผู้ขายขึ้นเท่ายอดบิลครั้งเดียว

อัปเดต / เปลี่ยนการตั้งค่า
  แตก zip ใหม่ ดับเบิลคลิก install.cmd แล้วกด Enter ตามค่าเดิม เปลี่ยนเฉพาะข้อที่ต้องการ
  (ไม่มี zip ใหม่: เปิด Command Prompt แบบ Administrator แล้วพิมพ์ C:\nukyok-agent\install.cmd)
  ระหว่างติดตั้ง Task หยุดไว้ชั่วคราว ถ้าตัวเชื่อมกำลังลงเอกสารอยู่ ตัวติดตั้งจะรอให้รอบนั้นเสร็จก่อนเปลี่ยนไฟล์
  ถ้าปิดหน้าต่างตัวติดตั้งก่อนขึ้น "ติดตั้งเสร็จ" ให้รัน install.cmd ใหม่ ไม่อย่างนั้นตัวเชื่อมจะหยุดอยู่
  (เว็บแจ้ง LINE Office เมื่อมีงานรอเกิน 1 ชั่วโมง)
  ตอบ n ปิดการลงน้ำมันหรืองานซ่อม: บิลชนิดนั้นที่รออยู่ย้ายไปที่ "ไม่สำเร็จ" ในหน้า Express (ไม่ลงเองภายหลัง)
  คีย์ใน Express เองแล้วกด "คีย์เองแล้ว" หรือกด "ลองใหม่" หลังเปิดการลงอีกครั้ง
  ตอบ n ที่น้ำมัน = ปิด R3 ด้วย: R3 ที่ยังไม่ได้เปิด (รอเปิด / รอ H3) ย้ายไปที่ "ไม่สำเร็จ" เช่นกัน
  ทำ R3 เองแล้วกด "ทำ R3 เองแล้ว" หรือกด "ลองใหม่" หลังเปิดการลงอีกครั้ง
